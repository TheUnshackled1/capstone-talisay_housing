## LIVE SYSTEM WORKFLOW

**Day 0**: Staff awards lot
  → Auto-create monitoring cycle + tasks

**Day 15**: Caretaker submits report
  → System evaluates, continues if progress shown

**Day 30**: Caretaker submits report
  → System escalates if no progress (creates explanation review)

**Day 30+**: Beneficiary gets SMS to explain
  → Staff approves/denies extension

**Extension**: Caretaker continues monitoring for 1-3 months
  → System re-evaluates at end

**Final Notice**: System issues 30-day final notice
  → Caretaker does final inspection

**Repossession**: System auto-blacklists and returns unit
  → Unit available for new award
