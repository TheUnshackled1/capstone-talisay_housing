### Phase 5: _evaluate_monitoring_report()

**Evaluation Rules**:

**Rule 1: Original 30-Day Period Non-Compliance**
```
IF:
  - days_since_award >= 30
  - construction_status = 'no_structure'
  - occupancy_status IN ('temporarily_vacant', 'unoccupied_abandoned')
THEN:
  - Create ExplanationReview (review_status='pending_review')
  - Send SMS: "No construction progress. Explanation required."
  - Set escalated=True
```

**Rule 2: Extension Period Non-Compliance**
```
IF:
  - monitoring_cycle.stage starts with 'extension'
  - today > monitoring_cycle.stage_end_date
  - construction_status = 'no_structure'
THEN:
  - Close current monitoring cycle
  - Create OccupancyMonitoringCycle (final_notice_30_day)
  - Create MonitoringTask (final_inspection)
  - Send SMS: "Final notice: 30 days to show progress by [DATE]"
  - Set escalated=True
```

**Rule 3: Normal Progress**
```
IF:
  - construction_status != 'no_structure' OR
  - occupancy_status = 'properly_occupied'
THEN:
  - status = 'progress_detected'
  - Continue normal monitoring
  - escalated=False
```

**Return Value**:
```python
{
    'status': 'normal|no_progress_detected|extension_failed|progress_detected',
    'actions': [{
        'type': 'explanation_review|final_notice|continue_monitoring',
        'message': 'Human-readable message',
        'review_id'|'cycle_id': 'UUID'
    }],
    'escalated': True|False,
}
```

## AUTO-ESCALATION WORKFLOW

```
Caretaker Submits Report
        ↓
Phase 4: submit_monitoring_report()
        ↓
MonitoringReport created
MonitoringTask marked 'completed'
        ↓
Phase 5: _evaluate_monitoring_report()
        ↓
Evaluation Rules Check:
├─ Rule 1: Day 30 no progress?
│  └─→ Create ExplanationReview
│  └─→ Send SMS
│  └─→ Mark lot_award as needs_explanation
│
├─ Rule 2: Extension failed?
│  └─→ Close old monitoring cycle
│  └─→ Create final notice cycle (30-day)
│  └─→ Create final inspection task
│  └─→ Send SMS
│
└─ Rule 3: Normal progress?
   └─→ Continue monitoring
   └─→ No escalation
        ↓
Return evaluation results in JSON
        ↓
Caretaker sees confirmation modal
```
